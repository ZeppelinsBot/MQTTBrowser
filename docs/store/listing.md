## Full description (max. 4000 characters)

MQTT Browser is a fast, clean MQTT client and topic explorer for Android.
Connect to any MQTT broker and explore its topics like a file tree — built
for developers, home-automation tinkerers, and anyone working with IoT data.

FEATURES

• MQTT client & explorer — browse every topic on a broker as an interactive
  tree, just like a file manager.
• Live messages — watch messages arrive in real time with per-topic message
  counts.
• Retained message handling — inspect retained messages, pick the one you
  want when several are available.
• Path-subscribe mode (new in v1.21) — subscribe to a single path
  (`<path>/#`) instead of the whole broker, plus a wildcard toggle to switch
  between wildcard (`#`) and path-based subscriptions.
• Wildcard toggle — switch between wildcard and path subscriptions with one
  tap; long-press any topic to subscribe instantly.
• TLS support — connect securely with server certificates, a custom CA
  certificate, or an explicit trust-all option for test brokers.
• Clean credentials handling — username/password auth, saved connections,
  and a reconnect prompt so you never lose your place.
• Fully local — no accounts, no cloud, no tracking. Your broker data stays
  between your phone and your broker.

MQTT Browser talks directly to the brokers you configure — public brokers,
your home server, a broker on your local network, or an industrial MQTT
gateway. Nothing else.
